# Calculadora de Contribuição ao INSS

Atividade de programação com uma calculadora de contribuição por faixas, acompanhada do fluxograma desenvolvido no Flowgorithm. Os parâmetros são informados no programa.

## Arquivos

- `calculadora-inss.cpp` — implementação em C++.
- `fluxograma-inss.fprg` — fluxograma editável no Flowgorithm.

> Exercício escolar: confira os parâmetros e regras vigentes antes de usar para qualquer cálculo real.
